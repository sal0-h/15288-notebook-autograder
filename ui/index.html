Gather Submissions

Upload a Gradescope export ZIP. Notebooks will be renamed by student and copied to the submissions folder.

What does row status "ok" mean after Gather?

ok = notebook was extracted and copied successfully. Specifically: metadata had a student name, submission folder existed, exactly one .ipynb file was found, no duplicate student name, and the file was copied to the submissions folder.

ok does NOT verify: that the notebook is valid/parseable, contains answers, or is for the correct assignment. Run Parse next to validate.

Export

        
Generate Gradescope autograder JSONs, an Excel spreadsheet, and refresh gradescope_autograder.zip in one step.

        
        

        

            Download Excel
            Download Linter Autograder ZIP
            Download Gradescope Autograder ZIP
        

        
Linter ZIP: pre-deadline format check (0 pts). Gradescope ZIP: post-deadline, uses pre-computed grades (id-keyed manifest when gather produced submitter_stem_map.json, plus legacy name map fallback).

        
Run Export already rebuilds the Gradescope ZIP. Download Gradescope Autograder ZIP runs export again first so the download always matches current graded_results.json.

        
Upload in Gradescope: Configure Autograder → Upload. Then run Manage Submissions → Rerun Autograders.
